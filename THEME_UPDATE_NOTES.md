# Monica Portfolio — Champagne & Mocha theme

## Changes
- Consistent cream/ivory backgrounds and warmer white card surfaces
- Dark mocha body text and muted text with improved readability
- Darker brown primary buttons/links for contrast, warm champagne highlights
- Removed leftover cherry-pink component colors from active pages, mobile navigation, badges and modals
- Changed the dark command search dialog to a warm light dialog
- Kept Monica’s current photos, page content, data, links, and component structure unchanged

## Run
`npm install` then `npm run dev` from this folder.

## Please review before publishing
- `src/data/resume.tsx` still contains links, skills, projects and experience inherited from the original template, including the original author's email/social handles. They were not changed because accurate replacements were not supplied.
- The contact form requires a working `VITE_FORMSPREE_URL` configured for your own Formspree form. Validate submission end-to-end before publishing.
- Theme is optimized for the current light design. Verify with real desktop/mobile browser screenshots.
