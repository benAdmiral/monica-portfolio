# Cherry Pop — theme update 🎀

This is a light-theme recolor of the uploaded Candy Glass React Portfolio project. It retains the original sample biography, projects and images for now; replace those before publishing.

## Run

```bash
npm install
npm run dev
```

## Theme colors

Edit `src/index.css` under `:root`:
- Background `#FFF5F7`
- Soft pink `#FFC0D2`
- Cherry primary `#EA648F`
- Dark rose text `#8A244C`

The `glass-card` and `glass-container` utility styles are also in `src/index.css`. Component-specific dark backgrounds were changed in `src/components/Layout.tsx`, `src/components/Navigation.tsx`, and `src/components/sections/`.
